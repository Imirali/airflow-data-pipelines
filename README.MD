# ETL пайплайн для выгрузки данных из SQL Server

## Задача

Компания-дистрибьютор стоматологических материалов ежедневно выгружает данные из учётной системы (MS SQL Server) для передачи партнёрам. Раньше это делалось вручную через C++ Builder приложение — сотрудник нажимал кнопку, программа подключалась к базе, выполняла хранимые процедуры и сохраняла файлы в нужном формате. Процесс требовал ручного вмешательства, не имел автоматического логирования и доставки файлов.

## Что сделано

Разработан ETL пайплайн на Python, который полностью автоматизирует этот процесс. Решение включает:

1. Автоматическое подключение к SQL Server и выполнение хранимых процедур для выгрузки 6 таблиц: клиенты, юрлица, товары, продажи, закупки и складские остатки.

2. Сохранение данных в двух форматах: TXT (с разделителем | для загрузки в старые системы) и CSV (с разделителем ; для Excel). На SFTP отправляются только TXT файлы — это требование принимающей стороны.

3. Архивирование предыдущей выгрузки: файлы за прошлый рабочий день автоматически перемещаются в папку с датой внутри `old/`. Учитываются выходные — если сегодня понедельник, архивируются файлы за пятницу.

4. Автоматическая загрузка на SFTP сервер с проверкой успешности (сравнение размера файла до и после загрузки).

5. Email уведомления о результате: при успехе приходит письмо со списком загруженных файлов и логами, при ошибке — с описанием проблемы. В письмо попадают только строки с SUCCESS или ERROR, чтобы не засорять почту.

6. Детальное логирование всех этапов с ротацией файлов — можно отследить, что и когда пошло не так.

7. Контейнеризация через Docker и оркестрация через Apache Airflow.

## Результат

Процесс полностью автоматизирован. Сотруднику больше не нужно вручную запускать программу и следить за выполнением — всё происходит по расписанию, с логированием, уведомлениями и автоматической доставкой файлов партнёру.

## Стек решения

- **Python 3.12** — язык разработки
- **pyodbc** — подключение к SQL Server
- **paramiko** — SFTP клиент
- **loguru** — логирование
- **python-dotenv** — управление переменными окружения
- **Docker / Docker Compose** — контейнеризация
- **Apache Airflow** — оркестрация пайплайнов
- **Windows Task Scheduler** — запуск по расписанию
- **Git / GitHub** — контроль версий
- **Microsoft SQL Server** — источник данных
